# RLAIF 评分细则（中文）

评审模型 Qwen3.8-27B 按这份细则给回答打分，分数就是 RL 的奖励。写于 2026-11-12，还没有用真实回答校准过。

## 怎么打分

- **分领域**：每条提示带一个领域标签：通用、写作、古文、诗词。评审先看通用细则，再看对应领域的细则。
- **用不思考的模式**：只输出下面这个 JSON，不要分析过程：

  ```json
  {"分数": 7, "理由": "一句话，说最主要的加分点或扣分点"}
  ```

- **分数 1–10**，按下面的档位给。
- **奖励怎么算**：奖励 = (分数 − 5.5) / 4.5，换算到 −1 到 1 之间；同一条提示的一组回答之间再做组内比较（GRPO）。
- **有参考答案时**：比如鲁迅续写给了原文，评审拿它当「好的样子」来比，但**不要求和参考相同**；大段照抄参考要扣分。
- **能用程序检查的不交给评审**：诗词的格律、字数、押韵由程序判，单独给分，再和评审的分数加权合起来（见「诗词」一节）。

### 档位

| 分数 | 意思 |
|---|---|
| 9–10 | 挑不出毛病，内容和语言都好，像高水平的人写的 |
| 7–8 | 好，有一两处小问题 |
| 5–6 | 能用，但平淡，或有明显但不致命的问题 |
| 3–4 | 有错误、答偏了，或语言明显不通顺 |
| 1–2 | 答非所问、编造事实、有害，或基本不可读 |

## 通用细则（所有回答都看）

**加分**：
1. **切题**：回答的是用户真正问的东西；有歧义时说明自己的理解。
2. **准确**：事实、计算、引文都对；不知道就说不知道。
3. **完整而不啰嗦**：该有的步骤和要点都有，没有凑字数。
4. **语言**：通顺、准确、没有语病；用词具体，不堆砌套话。
5. **格式**：长回答分段清楚；列表、表格、代码块用在该用的地方。

**扣分**（出现就压到对应档位以下）：

| 问题 | 最高给几分 |
|---|---|
| 编造事实、编造引文出处 | 3 |
| 答非所问 | 2 |
| 有害内容，或该拒绝时没拒绝 | 1 |
| 不必要的拒绝（问题正常却拒答） | 4 |
| 大段重复、车轱辘话 | 4 |
| 中英混杂、乱码、半截话 | 4 |
| 开头结尾的讨好式套话（「这是一个很好的问题！」「希望对你有帮助！」） | 扣 1 分 |
| 明显过长：比需要的长一倍以上 | 扣 1–2 分 |

## 写作（包括鲁迅相关的任务）

**看这几点**：
1. **语言质感**：用词准确，句式有长短变化、有节奏；不靠形容词堆砌。
2. **具体**：有细节、有画面，不空喊口号。
3. **结构**：开头、展开、收束连得上，段落之间有推进。
4. **立意**：有自己的看法，不停在人云亦云。
5. **符合要求**：题目、体裁、字数、视角都照办。

**仿写、续写某位作家的任务**：
- 看的是笔法有没有学到：句式、语气、讽刺的方式、观察的角度。
- **只堆砌这位作家的口头禅或名句，不算学到。** 比如反复写「我向来是不惮以最坏的恶意……」，算模仿痕迹太重，最高 5 分。
- 和参考原文大段相同（连续二十字以上照抄），最高 3 分。
- 续写要和前文接得上：人物、情节、语气不能断。

## 古文

1. **语法**：文言虚词、句式用得对（「之乎者也」不是装饰）。
2. **用字**：不混入明显的现代词汇（除非题目允许）。
3. **文意**：意思清楚，读得通。
4. **典故、史实**：用了就要用对；用错按「编造事实」处理。
5. **文白翻译**：
   - 把古文译成白话：准确第一，其次通顺；漏译、错译关键字要扣分。
   - 把白话写成古文：文意不走样，再看文言是否地道。

## 诗词

**程序检查的部分**（`training/rewards/` 里实现，不交给评审）：

| 项目 | 怎么判 |
|---|---|
| 字数、句数 | 五言、七言绝句、律诗，以及词牌的字数和句数 |
| 押韵 | 近体诗按平水韵，词按《词林正韵》，韵脚要在同一部 |
| 平仄 | 近体诗按格律谱；允许「一三五不论」的位置放宽 |
| 对仗 | 律诗颔联、颈联的词性大致对得上（用分词加词性标注粗查） |

格律分 = 各项通过的比例，0 到 1 之间。

**评审打分的部分**：
1. **意境**：有画面、有情感，不是押韵的大白话。
2. **用词**：精炼，有诗味，不生造词。
3. **立意**：切合题目，有新意。
4. **套话**：堆砌「明月、春风、相思」之类的现成意象，扣分。

**合起来**：诗词奖励 = 0.4 × 格律分 + 0.6 × 评审分（评审分先换算到 0 到 1）。
- **格律不过关，评审分最多算一半**：比如要求七绝却写成了八句，字数或押韵整体不对，免得模型靠意境分绕过格律。
- **自由体（新诗）**不查格律，只用评审分。

## 校准

### 第一次自动检查（2026-11-13，Qwen3.8-27B-4bit，`python -m tools.judge_check`）

每个领域取语料里的 12 个好回答，再各做几个故意弄坏的版本，看评审能不能把好的排在前面（「胜过」是好回答得分更高的比例，打平算一半）：

| 领域 | 好回答 | 截断 | 答非所问 | 车轱辘话 | 字序打乱 | 好回答胜过 |
|---|---|---|---|---|---|---|
| 通用 | 6.17 | 2.42 | 1.25 | 1.08 | | 92% / 96% / 100% |
| 古文 | 7.17 | 1.92 | 1.0 | （见下） | | 96% / 100% |
| 诗词 | 6.08 | | 2.58 | | 1.0 | 字序打乱 96%，答非所问 75% |
| 写作 | 2.5 | 1.83 | 1.83 | 1.17 | | 62% / 62% / 88% |

- 通用、古文、诗词：评审分得清好坏，180 次全部解析成功，每次约 3 秒（Mac 上一次只算一个，要用 `--judge-workers 1`–`2`）。
- 诗词「字序打乱」只得 1 分：格式对、意思没了的诗骗不过评审，不是只看格式。
- **写作**：「好回答」是鲁迅原文的下一段，评审认得原文，判成「照抄原文、没有创作」，只给 2–3 分（问它理由时它就这么说）。
  所以拿原文当正例校准不了写作题，要等有模型自己写的仿作再校准。实际 RL 时模型写的不是原文，不受影响；参考原文另外附上，细则里本来就要求「大段照抄要扣分」。
  第一次检查时还发现续写配错了：书信卷一段是一封信，「下一段」是另一封；日记的下一段是另一天；有时下一段只有一句。已经修了
  （`luxun_pairs` 跳过书信和日记，续写往后接到 150–400 字），SFT 语料和 RL 题目重新生成过。
- 古文的回答大多只有一句，「车轱辘话」就是原文，检查工具会跳过和原文一样的坏版本。

### 正式训练前

1. 从 SFT 模型的回答里抽 100 条，覆盖四个领域。
2. 人工打分，再和评审的分数对比；相关性不够，就改细则或评审的提示词。
3. 训练中每隔一段时间，看一眼固定提问的实际回答。奖励在涨、回答却变差时，说明模型在讨好评审，要停下来改细则。
